# Burn Demo Pages Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Three live demo surfaces per `docs/superpowers/specs/2026-08-12-burn-demo-pages-design.md`: a public `/Tour` page (new Tour section), three new tiles on `/Admin`, and an Engineering + dev-stats section on `/About`.

**Architecture:** Tour is a brand-new table-less vertical section at `src/Sections/Humans.Tour` modeled exactly on `Humans.Scanner` (the proven no-tables shape: no DbContext, no repository, empty `Section.Register`, internal controller discovered via `[assembly: Section]`). Admin tiles reuse existing service surface only. About reads a committed JSON snapshot generated by a script — no live GitHub API.

**Tech Stack:** ASP.NET Core MVC (.NET 10), Razor RCL sections, xUnit + AwesomeAssertions integration tests, PowerShell for the stats script.

## Global Constraints

- **English-only, deliberately unlocalized.** No resx files, no `Localizer` calls in any new view. Mark each new view/section with a short comment so a future i18n sweep doesn't "fix" it (precedent: the Lucy dedication comment in `Views/About/Index.cshtml:537`, and Gate's inline-English-by-design).
- **No new cross-section service surface.** Admin tiles use only methods that already exist. The spec's expenses/store tile is **dropped**: `Humans.Expenses.Contracts` exposes only `IExpenseReportBackgroundProcessor` and `Humans.Store/Contracts` is empty — a totals tile would need new public leaf surface, which needs Peter's approval. Say so in the PR.
- **Hard rules apply**: controller → service only; `I<Section>ServiceRead` for cross-section reads; HUM0034 makes any non-exempt public type in a section assembly a build error, so Tour's controller is `internal sealed`.
- Build: `dotnet build Humans.slnx -v quiet` (the `-v quiet` is mandatory). Tests: `dotnet test Humans.slnx -v quiet`, or `--filter` for one class.
- All work in the existing `burn-demo` worktree (`.worktrees/burn-demo`), commits pushed to `origin/burn-demo`.
- Never hand-edit EF migrations; this plan creates none.

# Generates src/Humans.Web/wwwroot/data/dev-stats.json for the /About engineering panel.
# Run from the repo root before a demo; commit the result. Never runs at app runtime.
$ErrorActionPreference = 'Stop'

$totalCommits = [int](git rev-list --count HEAD)

# Merged PRs on the fork (dev flow) + closed issues on upstream (the tracker).
$mergedPrs = [int](gh pr list --repo peterdrier/Humans --state merged --limit 1 --json number --jq 'length' 2>$null)
# gh caps list output; use the search API count instead for real totals.
$mergedPrs = [int](gh api "search/issues?q=repo:peterdrier/Humans+is:pr+is:merged&per_page=1" --jq '.total_count')
$closedIssues = [int](gh api "search/issues?q=repo:nobodies-collective/Humans+is:issue+is:closed&per_page=1" --jq '.total_count')

# Test count: attribute occurrences across test sources (HumansFact/HumansTheory included).
$testCount = (git grep -E '^\s*\[(Fact|Theory|HumansFact|HumansTheory)' -- 'tests/*.cs' | Measure-Object -Line).Lines

# Analyzer rules: distinct HUMxxxx diagnostic ids in the analyzer project.
$analyzerRuleCount = (git grep -ohE 'HUM[0-9]{4}' -- 'src/Humans.Analyzers/*.cs' | Sort-Object -Unique | Measure-Object).Count

# Per-author commit + line counts over the whole history.
$authors = @{}
$current = $null
git log --numstat --format='AUTHOR:%an' | ForEach-Object {
    if ($_ -like 'AUTHOR:*') {
        $current = $_.Substring(7)
        if (-not $authors.ContainsKey($current)) {
            $authors[$current] = @{ commits = 0; added = 0; deleted = 0 }
        }
        $authors[$current].commits++
    }
    elseif ($_ -match '^(\d+)\t(\d+)\t') {
        $authors[$current].added += [int]$Matches[1]
        $authors[$current].deleted += [int]$Matches[2]
    }
}
$contributors = $authors.GetEnumerator() | Sort-Object { $_.Value.added } -Descending | ForEach-Object {
    [ordered]@{ name = $_.Key; commits = $_.Value.commits; linesAdded = $_.Value.added; linesDeleted = $_.Value.deleted }
}

$claudeCommits = [int](git log --format='%(trailers:key=Co-Authored-By,valueonly)' | Where-Object { $_ -match 'Claude' } | Measure-Object).Count
$claudePercent = [math]::Round(100.0 * $claudeCommits / $totalCommits)

$out = [ordered]@{
    generatedDate = (git log -1 --format=%cs)
    totalCommits = $totalCommits
    mergedPrs = $mergedPrs
    closedIssues = $closedIssues
    testCount = $testCount
    analyzerRuleCount = $analyzerRuleCount
    contributors = @($contributors)
    claudeCoauthoredCommitPercent = $claudePercent
}
$json = $out | ConvertTo-Json -Depth 4
New-Item -ItemType Directory -Force "src/Humans.Web/wwwroot/data" | Out-Null
[System.IO.File]::WriteAllText("$(git rev-parse --show-toplevel)/src/Humans.Web/wwwroot/data/dev-stats.json", $json)
Write-Host "Wrote dev-stats.json: $totalCommits commits, $mergedPrs PRs, $closedIssues issues, $testCount tests, $analyzerRuleCount analyzer rules"
```

Note `generatedDate` uses the last commit date (deterministic) rather than today's clock.

namespace Humans.Web.Models;

/// <summary>
/// Deserialized shape of wwwroot/data/dev-stats.json — the committed snapshot written by
/// scripts/dev-stats.ps1. Nullable at the view: an absent file renders the Engineering
/// section without the numbers panel rather than failing the page.
/// </summary>
public sealed record DevStatsViewModel(
    string GeneratedDate,
    int TotalCommits,
    int MergedPrs,
    int ClosedIssues,
    int TestCount,
    int AnalyzerRuleCount,
    IReadOnlyList<DevStatsContributor> Contributors,
    int ClaudeCoauthoredCommitPercent);

public sealed record DevStatsContributor(string Name, int Commits, int LinesAdded, int LinesDeleted);
```

    [HttpGet("")]
    public IActionResult Index([FromServices] IWebHostEnvironment env)
    {
        // Committed snapshot, not a live API: demo must work on playa connectivity.
        DevStatsViewModel? stats = null;
        var file = env.WebRootFileProvider.GetFileInfo("data/dev-stats.json");
        if (file.Exists)
        {
            using var stream = file.CreateReadStream();
            stats = System.Text.Json.JsonSerializer.Deserialize<DevStatsViewModel>(
                stream, new System.Text.Json.JsonSerializerOptions { PropertyNameCaseInsensitive = true });
        }
        return View(stats);
    }
