## Assessment summary

Two of the three shapes `bdc9151a` set out to fix were still half-done, and the section's docs
described a database that does not exist.

`bdc9151a` (peterdrier/Humans#1645) converted every `IIssueTriage` member to take an `IssueViewer` and, in its own
review round, removed `IsAdmin` from the record's constructor because a privilege boolean on a
service signature is what `memory/code/authorization-conventions.md` forbids. It missed the one
member on the internal interface (finding 1) and the one controller action that still built its own
viewer (finding 2). History read this as the third instance of one defect class in three weeks — the
machine door handing the service state the service should derive — and it is now the last.

The docs were worse than stale. Four of them described `Restrict`/`SetNull` delete behaviour and
`HasOne<User>()` configuration on four columns (findings 5, 6), when the section configures no
cross-section foreign key at all and the baseline migration creates exactly one FK. One paragraph
described the GDPR purge backwards — reported issues persist under an anonymised name, it said,
where the section's own contributor deletes them. Three more claimed the machine door has no user
session and therefore a null audit actor (finding 7), a claim `bdc9151a` had already corrected in
one file and never swept into the others; the member-facing guide told readers an API comment could
not reopen a closed issue (finding 8), the inverse of what ships.

The localization gap was the only user-visible defect: `IssueStatus` had no key in any of the six
cultures (finding 3), so every status pill and the handler's status dropdown rendered English to
everyone, and the category filter on the list page rendered raw while two other views in the same
section localized the same enum through the same helper (finding 4).

Conformance is clean for Issues — the detector's one hit is the documented `Issue_` prefix. The
backlog is clean too: no open issue in either repo carries `section:issues`. Both facts were proved
before being recorded.
