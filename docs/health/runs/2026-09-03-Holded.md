## Assessment summary

Holded is two things sharing a project: the **ledger mirror** (a re-derivable local copy of
Holded's daybook and chart, with replace-window sweeps and per-account reconciliation) and the
**HTTP connector** that Finance, Expenses and Store all call. The target shape (`health.md`,
written before any scan) named that seam and its invariants; the assessment then found the code
holds nearly all of them and the *prose* holds almost none.

The genuine production defects were both named by the target rather than by any scan: the nightly
sweep could skip in silence (finding 2, invariant 5), and an account Holded sent without a number
became account `0` in the chart (finding 5, invariant 7). The rest of the volume is documentation
and comments asserting things the code does not do — most sharply finding 1, where the
general-ledger page's own summary claimed the opposite sign convention to the one it renders.

Deliberately not worked: the reforge score's top rows (`parameterBagInput`, `dtoScalarProperty`
on the connector's wire DTOs). Those DTOs mirror the Holded API's shape, which is not this
section's choice to make.
