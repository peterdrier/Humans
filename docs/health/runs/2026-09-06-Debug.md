## Assessment summary

First doctor pass over Debug, the developer's window onto the running process plus the
design reference (reforge 21, loc=1050, cogP95=7, cogMax=12): three admin controllers, no
tables, no service layer, every page a projection of a Base singleton's snapshot. The target
shape ([`health.md`](../../../src/Sections/Humans.Debug/Docs/health.md), written this run
before any scan) finds the code close to that shape as built. reforge's entire score is the
widget gallery's fan-in on other sections' read interfaces, which is the page's job.

No behavior bugs. What the section had instead was documentation that stopped tracking the
code: the invariant doc knew one controller where three exist and credited a test that did not
exist (finding 1), the contracts README described a nav tree the section replaced (finding 3),
csproj and source comments named projects deleted in the G5 split (findings 4, 10), and the
widget gallery told its reader to look for files at paths that moved (finding 5). The stated
invariants — admin policy, the two anonymous surfaces, masking, count clamps, the localizer
rule — had no test pinning them (finding 2). Three small code items the rules already ask for
(finding 7), one navigation dead-end (finding 8), one terminology slip (finding 9) and one dead
guard (finding 13) rounded out the strikes.

first pass under budget.

the scan, it stated as fact that `DebugArchitectureTests` pins the localizer rule — copied from
`Debug.md`, which was wrong. The threads caught it; the lesson is that a target written from
the invariant doc inherits the invariant doc's errors, and the independence check is what
surfaces them.
