## Findings

1. **An Open order with money on it can be deleted, and its payments go with it** (Behavior B1). `Service.DeleteOrderAsync` refuses only a non-zero balance on an Open order; a camp that has paid in full reads zero, and payments cascade on order delete (`OrderConfiguration`), so received money vanishes from the store ledger and the accounting export. An order holding only a Pending payment is deletable the same way. Behavior change — Needs Peter.
2. **`Service.GetOrderForTeamAsync` has no caller** in production or tests (Shape S1). Cut.
3. **Section and feature docs drifted from the code** (Freshness, History): a Settings dependency filed under Shifts, `ITeamServiceRead` missing from both dependency lists, treasury sync described as scheduled work and `IHoldedClient` issuance as paused, US-30.6 paused "alongside" a shipped US-30.5, the retired `IStoreServiceRead` narrated in `Store.md` and the Contracts README, the design record still "pre-implementation" and naming a `RecordManualPaymentAsync` that does not exist, the guide missing the Order years page and the Store admin nav group, and history narration.
4. **The admin controller re-derives the catalog-year rule** (Shape S2). `StoreAdminController.GetDefaultCatalogYearAsync` duplicates `Service.GetCurrentEventYearAsync` and injects `ISettingsService` and `IClock` only for it.
5. **Invariant pins missing** (Tests vs target §4): no test that a Pending payment blocks checkout, that every store-admin role is denied Pay / EditCounterparty / IssueInvoice on a team order, or that a camp lead never gets IssueInvoice or Delete. The reader's "issuance snapshot rewrite untested" was false — `ServiceIssueInvoiceTests.Writes_the_invoice_row_with_both_payloads_and_freezes_the_order` pins it.
6. **Comments narrate or triplicate** (Comments, History): the §15b boundary text restated across files, the one-counterparty invariant twice in `Order.cs`, caller naming in `IStoreRepository`, lane history in the csproj and `_ViewImports.cshtml`, retired-contract history in `Section.cs`.

8. **`Controller_requires_store_admin_policy` is subsumed** by the role theory beside it, which is misnamed for the order-year actions only (Tests).
9. **Issue review** (Inbox): nobodies-collective/Humans#1029, nobodies-collective/Humans#159, nobodies-collective/Humans#158 — recommendations only, in the PR body.
10. **The previous target was false about the public surface** and missed the accounting read and the order-year repair (target re-derivation). Fixed in `health.md`.
