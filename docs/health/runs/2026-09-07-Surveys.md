Second doctoring of Surveys, eleven days after the first and after ranked-choice voting and the
Asociado vote shipped (peterdrier/Humans#1559, #1577, #1581, #1585). The target shape in
[`health.md`](../../../src/Sections/Humans.Surveys/Docs/health.md) was regenerated before any scan
and gained a shape — **Decide** — because the section now runs a binding vote: eligibility at
entry, page and submit, a definition lock once open, an embargo while open, a precommitted ranked
count and a post-close availability recount. Structure did not move: still one service, one
repository, controllers split by audience, one page flow. "A vote is a survey with a flag, not a
second aggregate" is the new load-bearing sentence.

One behaviour defect (finding 1): the JSON download dropped ranked ballots while the CSV and
Markdown exports carried them, so a ranked question exported as an empty answer. One test that
did not test what its name said (finding 4). One admin label that fell through to an enum name
(finding 3). The rest is prose: the section's invariant doc had not learned about the vote at
all — four columns, two enum values, three routes and the branch-source rule were missing — and a
dozen comments still narrated a build plan or pointed at folders that no longer exist.

The largest reforge item (`largeClass SurveyService`, 85 pts, 2689 LOC) is again deliberately not
a finding; the target says the anonymity contract and now the embargo belong in one place. Its
ledger line is corrected (finding 9) so the growth reads as examined.
