## Retro

**What the selector/rubric got wrong:** nothing; it correctly declined to pick by formula when
every eligible section was previously doctored. The judgment fell to change volume, which is the
right axis for a re-doctor — the days since the first run carried behaviour fixes and
freshness sweeps through this section, and the docs had not kept up.

**Wasted motion:** the Freshness thread reported the moderation reason as optional in the code and
the guide as right; the controller requires it, so the guide was wrong and the spec right — one
verification round. Finding 9 was first probed by reading `EventInfo` in full when a grep for
`ActorName` answered it — and its first fix resolved the name in the controller when the view
already rendered the submitter through `<vc:human>`; Codex caught it, the second commit used the
component.

**What the assessment missed that striking revealed:** the reviewer found the time-zone
ternaries the dedup sweep left (`EventsAdminController`, `EventsCardViewComponent`) and a stale
`ToInstant` location claim in the very feature-doc section the run had kept; a literal-string sweep
for `GetZoneOrNull` before the strike would have found the controller's. The component's — a `.cshtml`
component deriving its zone from `EventGuideSettingsView` rather than `BurnSettingsInfo` — is not
the same helper's shape and was left as is.

**Target diff:** the section moved. The August target's erasure invariant did not exist because
the erasure ran around the cache (peterdrier/Humans#1492 fixed it); today's adds invariant 9 and the
GDPR-contributor placement as load-bearing weirdness. The earlier target was also under-described in
one place: it named "Programme answered five ways" without saying the API controller carries every
projection twice because favourites and browse return different records — that is the collapse
pressure the next run should strike at.

Auto-compactions landed in Phase 3's assess bucket and the Phase 4 comments strike (the cost
report places them); Phase 5's re-read of Phases 5–7 was applied after the second
(finding 16). The reviewer-gate row in the cost comment carries an opaque agent id instead of a
name because the `doctor-reviewer` dispatch prompt did not open with a `thread:` marker
(finding 17).
