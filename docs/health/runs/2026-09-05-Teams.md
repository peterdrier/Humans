## Assessment summary

First doctor pass over Teams, the largest never-doctored section after Users (reforge 1206,
loc=10715): the team graph, memberships, join requests, role slots, early-entry grants and
the system-team reconciler, behind a three-level read/write/management split with a
singleton caching decorator over a keyed-scoped inner service. The target shape
([`health.md`](../../../src/Sections/Humans.Teams/Docs/health.md), written this run before
any scan) finds the structure right as built, with one exception the target's own leaf rule
exposed: `ITeamService` on the Contracts leaf carried members that nothing outside the
assembly calls (finding 1), and one internal member nothing calls at all (finding 6).

No behavior bugs. What the section had instead was drift left by the G5 section migration:
the invariant doc and data-access map describing a layout two refactors old (findings 3, 4,
5), comment provenance narrating moves already made, a Hangfire-pin story repeated across
the leaf and the job, dangling crefs and a handful of plainly false comment facts (finding 9), dead resx
keys and one untranslated string (findings 7, 11), and duplicate or dead test scaffolding
(finding 8). The target itself was wrong on one point copied from a code comment — the
decorator clears wholesale on write, it does not mutate in place (finding 2). Invariants
the target lists were enforced but untested (finding 10); one of them turned out to be
enforced in the controller rather than the service (finding 16).

header named dependencies the service does not take (fixed in the comment strike).
