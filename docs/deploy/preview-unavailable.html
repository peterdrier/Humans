This preview environment isn't up yet

No app container answered this hostname. That's expected right after a PR is opened or pushed to, and usually one of these:

  • Database not cloned yet. Every PR preview needs its own database (humans_pr_<N>), cloned by the preview-db GitHub Actions workflow on the self-hosted runner. If that job is still queued or running, the app container starts, fails fast, and exits until the database exists. Check the PR's Actions tab for the preview-db run.
  • PR not deployed, or the URL is wrong. If Coolify has never deployed an app for this PR, there's nothing to boot at all. Check the PR number in the URL (https://<pr_id>.n.burn.camp) and that the PR is actually open.
  • PR closed. Its preview environment is torn down when the PR closes — this hostname will never resolve to a running app again.
  • Something else crashed on boot. Check the container logs for a FATAL line — startup failures always log one, naming what went wrong.
