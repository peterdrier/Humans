Every question put to Peter — /ask reports, Needs-Peter rulings, any decision list — is stated fully inline in the message itself, numbered and answerable cold. Never "findings by number in the run file", never "see the PR body", never a link in place of the question.

**Why:** Peter, 2026-09-09, on a section-doctor /ask that listed 8 Needs-Peter rulings by pointing at the PR body: "the point of /ask is to ask me the 'needs peter' rulings in line. NEVER refer me to another doc to read." He answers from a phone or a different session; a reference costs him a context switch the message was supposed to save.

**How to apply:** For each ruling: 2–4 self-contained sentences of background (what the code does, what the doc claims, why it matters), the question, and options with a recommendation — the /ask skill's per-item format applies to Needs-Peter queues too. A PR body or run file may *also* carry the queue for the record, but the message to Peter carries the full text. If the list is long, it's still inline — length is not an excuse to point elsewhere.
