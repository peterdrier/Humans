---
name: Section contributions are discovered files, not Section.cs edits
description: Adding a nav link, admin tile, job, policy, health check, endpoint, or chrome/dashboard component for a section → a separate ISectionContribution-derived class at the section root, never a method on Section.cs or an edit to a Shell composition class.
---

A section opts into Shell composition by adding a stateless class implementing one of the ten `ISectionContribution`-derived seam interfaces in `Humans.Base.Interfaces` (`ISectionNav`, `ISectionAdminNav`, `ISectionAdminTiles`, `ISectionChrome`, `ISectionMemberDashboard`, `ISectionThingsToDo`, `ISectionJobs`, `ISectionHealthChecks`, `ISectionEndpoints`, `ISectionPolicies`) — one file per seam, at the section project's root, with a parameterless constructor. `Section.Register` never grows a method for this; it stays the DI-registration entry point only.

**Why:** `SectionDiscoveryExtensions.RegisterContributions` finds every `ISectionContribution` implementation by the same dependency-graph walk `ISection` uses, and registers it as a singleton against every seam interface it implements. A new seam interface deriving from the marker costs Shell no edit; a method bolted onto `Section.cs`, or a by-name edit to a Shell composition class, isn't discovered by anything and just reopens the compile-time coupling nobodies-collective/Humans#1073 removes.

**How to apply:** need a section to show up in the admin sidebar, member top nav, a dashboard tile, a recurring job, a health check, an authorization policy, or a layout/dashboard chrome slot → add `Nav : ISectionNav`, `Jobs : ISectionJobs`, etc. at `src/Sections/Humans.<Section>/`. Never edit Shell's composition classes (`AdminNavComposition`, `SectionNavViewComponent`, `ChromeSlotViewComponent`, `RecurringJobExtensions`, `AuthorizationPolicyExtensions`, `Program.cs`) to name a section directly — that defeats the seam and blocks future section optionality (capstone lane #1081). See [`design-rules.md` §8b](../../docs/architecture/design-rules.md#8b-cross-section-fanout--contributor-pattern) for the seam catalog and composition/ordering rules.
